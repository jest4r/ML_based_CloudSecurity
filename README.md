# ML_based_CloudSecurity
This is the repo for my research and experiment on enhancing Core network Resistance and Resilience in Cloud Systems using ML models

## Summary

With the developing of AI and ML methods, some network systems can be improved their security and defense against cyber attacks. This project focuses on Enhancing the Resistance and Resilience of Core network in main cloud systems of some big data centers, by using ML and DL models to mainly detect, prevent and adapt to certain attacks like DDoS.

## Background

Some network systems are vulnerable to certain cyber attacks, especially when attackers can use a large amount of resources and botnets, with the help of AI. THis appears more and more frequently nowadays, put a lot of pressure on the system maintainers. My motivation mainly comes from my acknowledgements of Cloud Security and ML usages on improving system intelligence to identify patterns on attacks. This topic is one of the most controversial about Network Systems Security, especially for big data centers with billions of data.


## How is it used?

In the very first step, we mainly focus on understanding the process of DDoS or other similar attacks on network systems. We see that there are some certain patterns we could detect in order to govern some initial counter strategies. Then, while core network still resists, the ML methods will analyze the features of the attacks and based on that, manage to have an appopriate defense. Eventually, the system learns to adapt to improve its resistance and resilence with RL methods, workling just like our immune system.

## Challenges

This proposal may can not improve 100% the system after certain attacks, there have to be some trade-offs, nut we try our best to not let the system down and still manages to resist against attacks. Maybe further problems we still not see it yet, and the limitations mostly on the reality of the systems nowadays, it's hard to simulate them and also the cyber attacks. In addition, ethical consderations should be taken because these kinds of attacks mainly to break the system down and then steal their datas (mostly users data), so we should be really careful to simulate them.
